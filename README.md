# Vibe DM

Vibe DM is an open-source, smart Instagram DM automation platform consisting of a backend and a frontend.

## Project Structure

This is a monorepo structured as follows:

*   [`vibedm_backend/`](./vibedm_backend): The backend service, built with Python (FastAPI, Uvicorn, SQLModel/SQLAlchemy) and managed using the `uv` package manager.
*   [`vibedm_frontend/`](./vibedm_frontend): The frontend user interface, built with React, Vite, TypeScript, Tailwind CSS, and shadcn/ui.

## Getting Started
