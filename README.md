# Vibe DM

Vibe DM is an open-source application consisting of a backend and a frontend.

## Project Structure

This is a monorepo structured as follows:

*   [`vibedm_backend/`](./vibedm_backend): The backend service, built with Node.js/Express (or Python/Go depending on what's inside, we'll verify this).
*   [`vibedm_frontend/`](./vibedm_frontend): The frontend user interface.

## Getting Started

Refer to the README files in the respective subdirectories for setup and run instructions:
- [Backend README](./vibedm_backend/README.md)
- [Frontend README](./vibedm_frontend/README.md)
